Upload file esp32_web_logic.bin hasil idf.py build (di folder build/ project). Firmware baru ditulis ke partisi OTA yang SEDANG TIDAK AKTIF - partisi yang sedang jalan sekarang TIDAK disentuh sampai firmware baru terbukti valid. Device otomatis reboot setelah upload selesai. Kalau firmware baru gagal boot berulang kali, device otomatis ROLLBACK ke firmware lama dengan sendirinya - tidak akan ter-brick karena upload yang salah/corrupt.
