System > Modbus Slave

Node "Modbus Slave Reg" di editor expose register ke master Modbus RTU LUAR (SCADA/PLC dkk) lewat UART2/RS485 (pin TX=GPIO17, RX=GPIO16). Atur Slave ID dan Baud Rate di bawah - satu bus RS485 dipakai bersama SEMUA node modbus_slave_reg. Config baru baru aktif setelah device reboot - UART driver diinstall sekali saat boot, sama seperti alasan node HTTP Endpoint butuh reboot.
