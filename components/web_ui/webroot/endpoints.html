System > HTTP Endpoints

Node "HTTP Endpoint" di editor membuat route HTTP baru yang berjalan di SERVER KEDUA ini, port terpisah dari editor. Atur port-nya di bawah, lalu buka http://<ip-device>:<port>/<path> sesuai node yang sudah kamu buat. Route baru/berubah baru aktif setelah device reboot - server kedua mendaftarkan semua endpoint sekali saat boot.
